ServidorUm por usuário. Sem terminal de controle (TTY ?, PPID 1) — é por isso que sobrevive à queda do SSH.
SessãoAgrupamento nomeado. É a unidade de attach/detach: uma por assunto.
JanelaOcupa a tela toda, como uma aba. Numerada e renomeável.
PainelDivisão da janela; cada um com seu shell.
Cliente é o seu terminal: espia o servidor e pode sumir. C-b d e a queda da conexão têm o mesmo efeito — nada a salvar antes.

screen, o antecessor onipresente — prefixo C-a: screen -S nome cria · -ls lista · -r reconecta · -d -r expulsa o outro cliente · C-a d destaca. Só ele tem screen -x: dois usuários na mesma tela ao vivo. Aprenda esses cinco para a máquina antiga onde o tmux não existe.
kali@kali: ~ — o essencial e o ~/.tmux.conf
$ tmux new -As recon    # conecta se existir, cria se não — o idioma a memorizar
$ tmux ls
recon: 3 windows (created Sun Aug 31 09:00:12 2026) (attached)
$ tmux a -d -t recon    # reconecta e desconecta os outros clientes
$ tmux send-keys -t recon:1 'nmap -sV -oA scan alvo' C-m   # monta ambiente por script
$ tmux pipe-pane -o -t recon:1 'cat >> ~/logs/painel.log'  # grava o painel
# ~/.tmux.conf — as cinco linhas que mais mudam o dia:
set -g mouse on · set -g base-index 1 · set -g history-limit 50000
set -g renumber-windows on · bind | split-window -h -c "#{pane_current_path}"
⚡ Resumo rápido
  • O servidor roda sem terminal de controle; o seu terminal é só um cliente descartável.
  • Hierarquia: servidor → sessão → janela → painel. Sessão é a unidade de attach.
  • tmux new -As nome · tmux ls · tmux a -t nome · C-b d.
  • O histórico de rolagem é do tmux: use C-b [, não a roda do emulador (ou ligue mouse on).
  • Sessões sobrevivem a logout e à queda da conexão — não a reboot. Versione o script de montagem.
🐉 No Kali
Uma sessão nomeada por engajamento, com janelas recon, enum, exploit e notas. O layout de acompanhamento é ferramenta + htop + tail -f, com C-b z para ampliar. pipe-pane (ou script -a) grava o que foi executado — registro que protege as duas partes na discussão de uma indisponibilidade. No alvo é o contrário: subir tmux lá deixa servidor persistente, artefato que muda o estado do cliente. E confira ls -ld /tmp/tmux-* (deve ser 700): socket frouxo entrega uma sessão de root a quem quiser.
