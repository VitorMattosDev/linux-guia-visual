apt update → sudo !!!! repete a linha inteira. O idioma mais usado do histórico.
mkdir -p a/b/c → cd !$!$ é o último argumento · !^ o primeiro · !* todos · !nmap o último que começou assim.
^sysog^syslogRepete o anterior trocando a primeira ocorrência do texto. Conserta erro de digitação sem redigitar nada.
!!:pMostra sem executar, e deixa a linha na seta para cima. Use antes de todo !! que envolva sudo ou rm.
Ctrl+S congela · Ctrl+Q descongelaO motivo nº 1 de "meu terminal travou": a mão vai no Ctrl+S de salvar e o controle de fluxo para a exibição — o programa segue rodando. stty -ixon no ~/.zshrc desliga o susto de vez. (Ctrl+C, Ctrl+Z, Ctrl+D e estes dois são do driver do terminal, não do shell — por isso funcionam com o programa ocupado.)
alias ll='ls -lah' · mkcd() { mkdir -p "$1" && cd "$1"; }Alias para o que se repete; função quando precisa de argumento — alias não recebe. E fzf troca o Ctrl+R por busca difusa no histórico inteiro.
Tudo o que você digita fica em texto puro no histórico — senha inclusive. mysql -u root -pSenha123, curl -u admin:senha, hydra, sshpass: todos deixam rastro em ~/.zsh_history. Defesas: um espaço antes do comando com HIST_IGNORE_SPACE ativo, o HISTIGNORE='*password*:*token*' do Bash, ou o prompt interativo da própria ferramenta. A outra ponta também vale: num sistema que não é seu, o histórico é evidência — apagá-lo é ação registrada e, fora de escopo autorizado, crime no Brasil (Lei 12.737/2012). Do lado defensivo, é um dos primeiros arquivos que a resposta a incidente examina.
⚡ Resumo rápido
  • Ctrl+R é o atalho de maior retorno da ficha; Alt+. é o segundo.
  • Sem gravação incremental, a última aba a fechar vence e leva o histórico das outras.
  • HISTTIMEFORMAT / EXTENDED_HISTORY transformam o histórico numa linha do tempo do seu trabalho.
  • Tab é contextual: apt install completa pacotes, systemctl unidades, git checkout ramos. Tab duas vezes lista.
  • watch -d -n 2 'ls -lh coleta/' repete e destaca o que mudou.
🐉 No Kali
O Zsh do Kali já faz busca por prefixo nas setas: digite nmap e a seta para cima percorre só os comandos que começam assim — o recurso que mais economiza tempo depois do Ctrl+R. E aceita caminho abreviado: cd /u/s/w + Tab vira /usr/share/wordlists. O kali-tweaks não configura histórico — é edição manual, e acrescente ao fim do ~/.zshrc. EXTENDED_HISTORY vira insumo direto de relatório num teste autorizado: o que rodou, contra quem e quando (combine com script -T tempo.log sessao.log para gravar a sessão inteira, saída incluída). E Ctrl+C numa varredura longa perde o progresso: comece sempre com -oA/-o — só com saída em arquivo o --resume funciona — e prefira tmux a deixar a varredura presa à aba.
