O mesmo nome existe em seções diferentes
1
Comandos de usuárioTudo que se digita. man 1 passwd = trocar senha
2
Chamadas de sistemaA fronteira com o kernel — open(2)
3
Funções de bibliotecaC e glibc — printf(3)
4
Arquivos especiaisDispositivos em /dev
5
Formatos de arquivoA sintaxe da configuração. man 5 passwd = /etc/passwd

JogosHerança histórica do Unix

8

Sem o número, o man entrega a seção 1. Por isso man passwd mostra o comando e man 5 passwd mostra o formato do arquivo. whatis passwd lista todas as seções em que o nome existe; man -a passwd percorre uma a uma. O número entre parênteses numa referência — crontab(5) — é exatamente isso: onde procurar.

⚡ Resumo rápido
  • Doc local sempre casa com a versão instalada; artigo na internet, não. Divergiu? a local está certa.
  • tldr para lembrar a forma usual, man para o detalhe e o caso de borda.
  • apropos vazio? o índice não existe: sudo mandb.
  • whereis · dpkg -S $(which x) · file $(which x) — se for script, dá para ler.
🐉 No Kali
Muita ferramenta do Kali não tem página de manual — são projetos de comunidade. O caminho é -h (e não --help), depois o nome sozinho, depois kali.org/tools, que documenta cada ferramenta empacotada; kali.org/docs cobre a distribuição. Módulos do Metasploit se documentam dentro do console (info <modulo>, show options). Em imagem headless ou contêiner o man costuma ter sido removido: apt install --reinstall man-db manpages. Depois de instalar um metapacote, rode sudo mandb. Comando colado sem leitura é comando não auditado — vale para fórum, artigo e IA.
