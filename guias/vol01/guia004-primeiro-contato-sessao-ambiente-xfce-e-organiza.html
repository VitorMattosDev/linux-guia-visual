Terminalo seu prompt
A camada gráfica é a única dispensável. systemctl get-default mostra o alvo; set-default multi-user.target entrega um sistema completo sem tela — é o que se faz em servidor. E a saída de emergência quando o Xfce trava é Ctrl+Alt+F3: um console virtual ligado direto ao kernel. Ctrl+Alt+F7 (ou F2) volta — a sessão gráfica continuou rodando o tempo todo.

Os quatro ajustes do primeiro dia
kali@kali: ~
$ setxkbmap -model abnt2 -layout br    # teclado ABNT2 já nesta sessão
$ sudo dpkg-reconfigure keyboard-configuration   # torna permanente
$ sudo timedatectl set-timezone America/Sao_Paulo # log com hora errada não correlaciona
$ timedatectl set-ntp true
$ mkdir -p ~/lab/{alvos,capturas,notas} ~/clientes # cliente nunca no lab
# Sistema em INGLÊS + teclado em português: erro em português quase não se pesquisa.
⚡ Resumo rápido
  • Uma árvore só, começando em /: sem letra de unidade. ~ é onde você escreve sem sudo.
  • Nome começando com ponto é oculto — ls -a mostra. É onde vivem as configurações.
  • Maiúscula ≠ minúscula: Documentos e documentos são dois diretórios.
  • ~/.config/xfce4 é o seu ambiente inteiro — copiável para outra máquina.
🐉 No Kali
O menu de treze categorias numeradas é uma metodologia disfarçada: elas seguem as fases de uma auditoria — 01 coleta → 02/03/04 análise → 05/08 exploração → 09/10 pós-exploração → 11/12 forense e relatório. Categoria vazia = ferramenta não instalada, não menu quebrado: instale o metapacote da área. Xfce é padrão desde 2019.4 e Zsh desde 2020.4 (chsh -s /bin/bash troca). Serviços de rede vêm desabilitados: ferramenta que "não conecta no banco" é quase sempre o PostgreSQL parado.
