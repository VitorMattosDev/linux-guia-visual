Para o shell, todas as palavras depois do comando são iguais. Quem decide que -sV é opção e o resto é alvo é o programa, ao ler seu vetor de argumentos — por isso não existe sintaxe universal. Curtas sem valor se agrupam (ls -lah); -- marca o fim das opções e salva de nome de arquivo que começa com traço: rm -- -arquivo-estranho. E há os rebeldes: tar xzf, ps aux, dd if=... of=... — sem traço nenhum.

type -a <comando> mostra qual das cinco venceu — e explica por que o terminal e o script se comportam diferente. O diretório atual não está no PATH: por isso ./script.sh. Não é inconveniência, é segurança — com . no PATH, um arquivo chamado ls num diretório gravável vira escalada de privilégio. Nunca acrescente . ao PATH.

a && bRoda b só se a deu certo. O padrão para tudo que pressupõe o passo anterior.
a || bRoda b só se a falhou — o tratamento de erro.
a ; bRoda b sempre, dê no que der.
a &Roda em segundo plano e devolve o prompt na hora.
\rm · command rmIgnora o alias e chama o programa real.
Trocar && por ; já destruiu sistemas. Em cd /tmp/trabalho ; rm -rf ./*, se o cd falhar por um erro de digitação, o rm -rf executa no diretório em que você estiver — que pode ser o seu ~. Escreva sempre cd /tmp/trabalho && rm -rf ./*. Mesma família de erro: em rm -rf "$DIR"/ com $DIR vazia, a linha vira rm -rf /. E sudo echo x > /etc/arquivo falha: quem redireciona é o seu shell, não o sudo — use echo x | sudo tee -a /etc/arquivo.
⚡ Resumo rápido
  • Ler → separar por espaço → expandir → resolver → fork → execve. O programa só existe no fim.
  • Espaço em nome quebra tudo: "$arquivo" entre aspas, sempre.
  • hash -r (Bash) ou rehash (Zsh) quando o shell não acha o programa recém-instalado.
  • O shell é só mais um programa: ps -p $$ -o comm= mostra qual está rodando de verdade.
🐉 No Kali
O shell padrão é o Zsh desde a 2020.4 — para tudo desta ficha ele é idêntico ao Bash; use rehash no lugar de hash -r. A distro define aliases coloridos para ls, grep, ip: veja com alias e lembre que script nenhum os enxerga. Ferramenta clonada em /opt não está no PATH — faça um link em /usr/local/bin. Cuidado com comando copiado de artigo: dá para esconder um comando extra num bloco formatado. Cole num editor antes de executar — o shell obedece à linha, não à sua intenção.
